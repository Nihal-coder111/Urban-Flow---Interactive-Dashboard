An interactive Streamlit based web application to visualize, filter, and analyze large-scale urban mobility and Origin-Destination-Time (ODT) flow patterns.

---

## Overview

This dashboard visualizes passenger flow patterns derived from taxi trip data in New York City. It implements the **Generalized ODT Pattern** mining concept, allowing users to explore both atomic (single-zone) and generalized (multi-zone) movement patterns through an intuitive web interface.

### Key Features

| Feature | Description |
|---------|-------------|
|  **Interactive Map** | Click on Manhattan zones to explore flow patterns |
|  **Generalized Patterns** | Merge adjacent zones into origin regions |
|  **Destination Heatmaps** | Visualize hotspots and high-traffic areas |
|  **Statistical Analytics** | Real-time metrics and interactive charts |
|  **Pattern Drill-Down** | Explore individual flow contributions |
|  **Export Data** | Download patterns as CSV or JSON |
